# EVO LABS — UNIVERSE OPERATING SYSTEM

## Propósito
EVO LABS no es una academia tradicional ni una colección de tutoriales.

Es un sistema de evolución técnica que transforma a una persona sin conocimientos en un operador avanzado capaz de:
- comprender;
- observar;
- medir;
- experimentar;
- diagnosticar;
- reparar;
- optimizar;
- documentar;
- enseñar;
- crear.

La experiencia debe ser comprensible para un niño en la capa inicial y suficientemente profunda para formar a un profesional.

## Principio central
CLARIDAD PARA ENTRAR.
PROFUNDIDAD PARA CRECER.
EVIDENCIA PARA AVANZAR.
ORDEN PARA NO PERDERSE.

## Arquitectura del Universo EVO

### 1. MUNDO EVO — CENTRO DE OPERACIONES
La pantalla que responde:
- ¿Dónde estoy?
- ¿Qué estoy aprendiendo?
- ¿Qué puedo hacer ahora?
- ¿Qué desbloqueé?
- ¿Qué me falta?
- ¿Cuál es mi siguiente mejor acción?

Nunca debe sentirse como un menú genérico.

### 2. APRENDER — CONSTRUIR MODELOS MENTALES
Contiene los 10 Tomos.

Cada conocimiento se presenta por capas:
1. ENTENDER — explicación humana y visual.
2. PROFUNDIZAR — precisión técnica.
3. HACER — acción práctica.
4. COMPROBAR — evidencia.
5. CONECTAR — relación con otros conocimientos.
6. DOMINAR — caso real o evaluación.

### 3. PRACTICAR — APRENDER HACIENDO
Laboratorios, simuladores, experimentos y casos.

Un Lab EVO no es una demo.
Es un banco de pruebas.

Flujo:
OBJETIVO -> ESCENARIO -> OBSERVACIÓN -> HIPÓTESIS -> ACCIÓN -> MEDICIÓN -> INTERPRETACIÓN -> RIESGO -> REVERSIÓN -> COMPROBACIÓN -> EVIDENCIA -> CONCLUSIÓN.

### 4. ANALIZAR MI PC — REALIDAD
Zona de diagnóstico real.

Separar estrictamente:
- datos reales;
- datos reportados por el sistema;
- datos derivados;
- estimaciones;
- simulaciones.

Nunca inventar telemetría.

### 5. HERRAMIENTAS — INSTRUMENTOS
Herramientas reutilizables:
- terminal;
- comandos;
- visor de eventos;
- procesos;
- servicios;
- red;
- hardware;
- rendimiento;
- comparación;
- auditoría.

Una herramienta no enseña por sí sola: ayuda a medir o actuar.

### 6. MI EVO — IDENTIDAD TÉCNICA
Debe registrar:
- progreso;
- resultados;
- expedientes;
- casos resueltos;
- máquinas analizadas;
- habilidades;
- insignias;
- certificados;
- historial;
- próximos objetivos.

MI EVO muestra evolución real, no puntos vacíos de gamificación.

## Sistema cognitivo
Cada pantalla debe reducir carga mental.

Reglas:
- una acción principal;
- máximo dos secundarias;
- agrupación por intención;
- no más información de la necesaria para la decisión actual;
- profundidad progresiva;
- mostrar contexto siempre;
- nunca dejar al usuario sin siguiente paso;
- evitar jerga antes de explicarla;
- usar jerga profesional después de comprenderla.

## Diseño de información
Todo contenido debe responder, en orden:
1. ¿Qué es?
2. ¿Para qué sirve?
3. ¿Dónde está?
4. ¿Cómo se observa?
5. ¿Cómo se mide?
6. ¿Qué puede fallar?
7. ¿Cómo se prueba?
8. ¿Qué riesgo tiene?
9. ¿Cómo se revierte?
10. ¿Cómo sé que quedó bien?

## Sistema de prompts EVO
Los prompts de desarrollo serán cortos y versionados.

Formato:
1. ESTADO
2. OBJETIVO
3. NO TOCAR
4. CAMBIO EXACTO
5. CRITERIOS DE CALIDAD
6. VALIDACIÓN
7. REPORTE
8. STOP

Nunca volver a explicar todo EVO en cada prompt.

Los principios permanentes viven en documentos canónicos del repositorio.

## Evolución rápida guiada
Cada ciclo:
AUDITAR -> PRIORIZAR -> IMPLEMENTAR -> VALIDAR -> COMPARAR -> CONSOLIDAR -> SIGUIENTE.

No abrir 20 frentes simultáneos.
Trabajar el cuello de botella que más valor agrega.

## Jerarquía de calidad
Nivel 0: existe.
Nivel 1: funciona.
Nivel 2: es claro.
Nivel 3: enseña.
Nivel 4: permite practicar.
Nivel 5: genera evidencia.
Nivel 6: conecta conocimientos.
Nivel 7: desarrolla criterio.
Nivel 8: transfiere a problemas reales.
Nivel 9: permite crear.
Nivel 10: convierte al usuario en referente.

Nada se considera PRO sólo por funcionar.

## Estándar editorial
El contenido debe ser:
- original;
- técnicamente preciso;
- visualmente ordenado;
- progresivo;
- medible;
- verificable;
- accionable;
- memorable;
- conectado al resto del universo EVO.

Prohibido relleno.
Prohibida repetición disfrazada.
Prohibido contenido genérico que podría pertenecer a cualquier curso.

## Regla de unicidad
Si una pantalla, explicación, Lab o herramienta podría intercambiar el logo EVO por otro y seguir pareciendo el mismo producto, todavía no tiene suficiente identidad EVO.

## Resultado esperado
Una persona entra sin saber qué es un proceso y, siguiendo el sistema, puede terminar:
- leyendo telemetría;
- razonando hipótesis;
- diagnosticando fallas;
- usando herramientas profesionales;
- documentando evidencia;
- reparando sistemas;
- optimizando con método;
- creando soluciones propias;
- enseñando a otros.

Ese recorrido completo es EVO LABS.
